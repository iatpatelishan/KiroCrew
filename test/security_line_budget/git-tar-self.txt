The `sandbox-escape-git-tar-self` floor: a new `argv_floor_git_tar` module that
refuses a git or tar command whose transport dials this host (a literal self host,
an `ext::` / `ssh://` URL, `core.sshCommand` / `GIT_SSH` / `GIT_SSH_COMMAND`, tar's
`--rsh-command`, `TAR_OPTIONS` or `TAPE`, an `--upload-pack` / `--receive-pack`
program). It reuses the ssh floor's source pre-walk (`_ssh_floor_source_text`, split
out of `_is_ssh_to_self` with no change in what the ssh floor reads) and its
environment tracker (`_FrameEnvironment`). The open-quote backstop reads its
expansion signals (`$(`, `${`, `$NAME`, a run of one or two backticks) from the
command as submitted, because the normalizer drops those markers. Deny-only: it
adds refusals and removes no rule.
